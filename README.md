# AgentForce HQ

GitHub-ready static sales website for the AI Workforce-in-a-Box offer.

## Publish

1. Create a new GitHub repository named `agentforce-hq`.
2. Upload `index.html`, `styles.css`, and `README.md`.
3. Replace `YOUR_EMAIL@example.com` and `YOUR_STRIPE_OR_GUMROAD_LINK` in `index.html`.
4. Connect the repository to Vercel or enable GitHub Pages.
